Executive summary

The working HOJ pilot demonstrates a commercially meaningful slice of the provisional’s story: physical scan → unit identity → gated generative persona (Myra) → persistent ledger memory → usage metering → brand dashboard. The strongest overlap is generative persona + stateful memory + scan-triggered authorization + per-unit codes. The largest gap is patent Layer C (material/NPU liveness), cryptographic fusion, and decentralized ledger/DID — the prototype uses Gemini vision prompts for “Layer 2/3” and Supabase Postgres instead of smart contracts.

Do not present the prototype as implementing silicon sub-20ms indexing, IMU power-gating, steganographic decode, or on-device SLM — these are [FUTURE / R&D] or [DISCLOSED IN PROVISIONAL] only.

Part 1 — Current prototype (forensic)

End-to-end flow [CURRENTLY IMPLEMENTED]

  1. Browser loads React app; MindAR tracks public/targets.mind (Layer A UX).
  2. On target found: anchor video → canvas frame → verifyHojProduct() (Gemini image + VERIFY_SYSTEM).
  3. On REAL: code matched to ledger_threads.verification_code; device_id binds sender/receiver seats.
  4. isVerified unlocks mic/chat; Gemini + Inworld/ElevenLabs; lines persist to Supabase.
  5. Exit: Archivist summaries to session_summaries; token/voice usage appended.

Not implemented [NOT FOUND]

  • QR decode library; NPU/microtexture; blockchain/DID; crypto fusion; runtime budget hard-stop; image redaction before cloud verify.

Part 12 — Core IP reality check

  1. Strongest in prototype: Product-bound Myra persona with sender/receiver memory on verified unit codes.
  2. Strongest in provisional: Tri-layer auth + fusion-gated generative persona + ledger/quota abstraction.
  3. Overlap: Scan-gated AI session, unit identity, persistent memory, usage accounting.
  4. Far apart: NPU liveness, crypto fusion, DID/smart contracts, hardware indexing.
  5. Demo vs architecture: Meaningful architecture partially demonstrated — not mere slideshow.
  6. Third-party heavy: Gemini, MindAR, Three.js, Inworld, Supabase, Netlify.
  7. Own orchestration: Verify protocol, ledger pairing, prompts, metering, dashboard, session roles.
  8. Biggest weakness: Liveness not empirically validated; Layer C not implemented.
  9. Biggest patent-support risk: Examiner compares claims to prototype and finds only cloud prompts.
  10. Build next: Evidence-grade verify/spoof tests + explicit fusion/metering gates.
  11. Do not waste 5 mo on: Full blockchain royalty engine, steganographic printing, SoC indexing.
  12. Take to attorney now: Mapping table + honesty on Layer C + ledger embodiment breadth.
