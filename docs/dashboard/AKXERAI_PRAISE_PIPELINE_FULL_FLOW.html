1. Executive summary

The Admin Dashboard does not scan raw conversation text with keyword regex for brand/Akxerai praise or issues. It reads structured labels written by a dedicated Gemini call (the Archivist) at scan end into session_summaries. If that call never runs or output is replaced by local_fallback, dashboard tiles stay empty until backfill on dashboard load re-runs the same Archivist.

Golden rule: conversation → (optional) Archivist → session_summaries labeled blocks → parseLabeledQuoteBlock / parseAkxeraiExperienceFeedback → buildBrandDashboardAnalytics → Overview tiles.

4. Archivist Gemini — prompts

4.1 System instruction (constant)

Export: MYRA_SESSION_SUMMARY_SYSTEM in myraSummarize.js. Passed as systemInstruction in requestSummary(). Role: "Akxerai Soul Ledger Archivist — NOT Myra."

Dashboard-relevant section (verbatim intent from code):

DASHBOARD SIGNALS — MISSION INSIGHTS (concept labels, not keyword lists)
Purpose: leadership reads ONLY these labeled blocks. The app does NOT search chat for words.

DISCOVERY — how user found House of Jewels / product
  If yes: DISCOVERY: yes | "exact user words from log"
  If none: DISCOVERY: none

BRAND PRODUCT PRAISE — HOJ product, showroom, staff, packaging, shop trust
  If yes: BRAND PRODUCT PRAISE: yes | "exact user words from log"
  If none: BRAND PRODUCT PRAISE: none

AKXERAI PRAISE — Myra persona, digital keepsake delight
  If yes: AKXERAI PRAISE: yes | "exact user words"
  If none: AKXERAI PRAISE: none

BRAND PRODUCT CRITICISM — shop/product dissatisfaction
  If yes: BRAND PRODUCT CRITICISM: yes | "exact user words from log"
  If none: BRAND PRODUCT CRITICISM: none

AKXERAI EXPERIENCE FEEDBACK — positive OR negative on AI/tech (not jewellery counter)
  Categories: persona | voice | scan_flow | ar_vr | speed | trust | other
  If none: AKXERAI EXPERIENCE FEEDBACK: none
  If yes: AKXERAI EXPERIENCE FEEDBACK: positive | category: <cat> | "exact user words"
     or: AKXERAI EXPERIENCE FEEDBACK: negative | category: <cat> | "exact user words"

MYRA BRAND LINES — Myra lines as HOJ brand voice (bullets) or none

CLASSIFICATION DISCIPLINE:
• Same quote must not appear in two dashboard blocks.
• One user quote → at most one primary block (mixed monologue → strongest fit or none for all three).
• Prefer none over weak label.

4.2 User prompt (per call)

Function: summarizeSessionDialogue({ dialogue, roleKey, scanNumber, priorSummaries })

Sender user prompt ends with: output THREAD: Sender, DIALOGUE DIGEST, MYRA LAST STATE, SESSION END, then DISCOVERY, BRAND PRODUCT PRAISE, BRAND PRODUCT CRITICISM, AKXERAI PRAISE, AKXERAI EXPERIENCE FEEDBACK, MYRA BRAND LINES.

Receiver user prompt: THREAD: Receiver, SCAN CONVERSATION (verbatim myra+receiver), same dashboard headers.

Input body: labelled log lines only from current scan. Optional prior summaries truncated (~5000 chars).

4.3 Model chain

SUMMARY_MODEL_CHAIN = gemini-3.6-flash, then gemini-3.5-flash-lite, gemini-3.1-flash-lite. maxOutputTokens 8192, temperature 0.25. Production uses Netlify proxy when USE_API_PROXY.

5. Expected Archivist output (logical schema)

  1. THREAD: Sender | Receiver
  2. Sender: DIALOGUE DIGEST (myra short labels; sender full quoted lines with light STT cleanup)
  3. Receiver: SCAN CONVERSATION (full verbatim myra + receiver)
  4. MYRA LAST STATE (was_asking, user_answered; was_teasing on receiver)
  5. SESSION END (reason, detail, last_user_line, resume_hint)
  6. All DASHBOARD SIGNAL blocks listed above

Plain text only — no markdown.

6. Supabase storage format

6.1 Column: session_summaries

Multiple scans appended. Each scan = envelope from buildSessionSummaryEntry():

--- session 2 summary (Sender) ---
date: ...
started: ...
ended: ...
duration: 1 min 30 sec
return_gap: ...                    (optional)
summary:
<FULL ARCHIVIST BODY — multiline>
brand_praise: "..."               (optional — only if parse at save time)
praise: "..."                     (duplicate shortcut)
axerai_praise: "..."              (optional — also reads akxerai_praise alias)

Not stored as top-level shortcuts: brand criticism, discovery, Akxerai experience feedback, Myra brand lines — only inside summary: body.

6.2 Column: conversation

After scan end footer:

--- session N end ---
session-started: ...
session-ended: ...
session-duration: ...
session-view-ar-seconds: ...       (optional)
session-praise: "..."              (optional — BRAND praise only, from save-time parse)

7. Repair, fallback, fastExit

7.1 repairSessionSummaryFromDialogue()

After Gemini returns text, validates THREAD label, sender digest line count, receiver SCAN CONVERSATION. If invalid or too thin → replaces entire output with buildLocalStorySummary() which sets:

DISCOVERY: none
BRAND PRODUCT PRAISE: none
AKXERAI PRAISE: none
BRAND PRODUCT CRITICISM: none
AKXERAI EXPERIENCE FEEDBACK: none
MYRA BRAND LINES: none
SOURCE: local_fallback

Even if Gemini had correct praise blocks, they are lost on this fallback path.

7.2 Gemini failure

buildSessionSummaryAndPraise catch → same local fallback; log: "local fallback summary — brand praise requires Gemini".

7.3 fastExit (pagehide)

Never calls Archivist. Same local_fallback body. Dashboard tiles empty until backfill.

7.4 summaryEntryNeedsRebuild()

Backfill re-runs Archivist if summary contains SOURCE: local_fallback, empty digest, missing sender lines in DIALOGUE DIGEST, etc.

8. Dashboard load + backfill

AdminDashboard.jsx on auth: for each ledger row with scan_count > 0 and conversation containing --- session, calls backfillThreadSummariesFromConversation(thread, role).

For each ended scan with user speech: if summary missing or needs rebuild → buildSessionSummaryAndPraise (same Archivist) → UPDATE session_summaries in Supabase.

9.1 parseLabeledQuoteBlock (praise, criticism, discovery)

Accepts:
  LABEL: none
  LABEL: yes | "single line quote"
  LABEL: yes - "quote"  (loose)
  LABEL: "quote"        (direct)
Quote max 220 chars in parser output.

9.2 parseAkxeraiExperienceFeedback

AKXERAI EXPERIENCE FEEDBACK: none
AKXERAI EXPERIENCE FEEDBACK: negative | category: voice | "the voice was a little slow"
(Does NOT use "yes |" pattern)

9.3 parseSessionSummaryDetails (myraLedger.js)

Splits session_summaries envelopes, extracts summary body via extractSummaryBodyFromSessionBlock, merges shortcut lines brand_praise/praise/axerai_praise with parser results into session rows used by buildDashboardAnalytics.

10. Dashboard aggregation → UI tiles

buildBrandDashboardAnalytics() in brandDashboard.js:

  • Per verification code, per session in buildDashboardAnalytics.sessions
  • summaryText = session.summary (Archivist body)
  • brandPraiseQuote = session.brandPraiseQuote || parseBrandProductPraise(summaryText).quote
  • brandCriticismQuote = parseBrandProductCriticism(summaryText).quote (no envelope shortcut)
  • akxeraiPraiseQuote = session shortcut || parseAkxeraiPraiseFromSummary
  • akxeraiFeedback[] from parseAkxeraiExperienceFeedback when detected
  • Push into arrays: brandPraise[], brandCriticism[], akxeraiPraise[], akxeraiFeedback[], brandDiscovery[]

Overview tiles (AdminDashboard OverviewView)

TileData source
Brand praise countbrand.brandPraise.length (tap → sheet)
Akxerai praise countbrand.akxeraiPraiseCount (= akxeraiPraise array length only)
Brand issuesbrand.brandCriticism.length
Akxerai issuesakxeraiFeedback where sentiment === 'negative' (NOT akxeraiPraise)

Note: Positive AKXERAI EXPERIENCE FEEDBACK counts on Akxerai tab sentiment but NOT on Overview "Akxerai praise" tile.

Comment in brandDashboard.js: "Archivist concept blocks in session_summaries only — no keyword scan on raw conversation."

11. Semantic vs keyword

Design (A): Semantic — Archivist classifies by meaning into labeled blocks.

Actual (C) mixture:

  • Primary: parse labeled blocks from session_summaries body (A)
  • Shortcuts: brand_praise / axerai_praise lines in envelope (A)
  • conversation footer session-praise merges brand quote only (not keyword mine of dialogue)
  • Raw conversation dialogue NOT regex-scanned for "staff" / "Myra" etc. on dashboard path (B avoided)

12. Known mismatches / failure modes

  1. Prompt conflict: "one quote → one block" / "mixed → none for all three" vs product need for multiple tiles from one utterance.
  2. local_fallback + fastExit: all signals none → empty tiles until backfill.
  3. repairSessionSummaryFromDialogue: digest validation failure wipes Gemini dashboard blocks.
  4. Parser: strict single-line yes | "quote"; multiline or missing yes fails.
  5. UI: Overview Akxerai praise ignores positive experience feedback.
  6. Storage: criticism/negative feedback not duplicated as top-level fields — lost if body truncated.

13. Worked example

User (sender): "The jewellery is beautiful and the showroom staff was very helpful. Myra was really fun, but the voice was a little slow."

Ideal Archivist output (if rules allow split slices)

BRAND PRODUCT PRAISE: yes | "The jewellery is beautiful and the showroom staff was very helpful."
BRAND PRODUCT CRITICISM: none
AKXERAI PRAISE: yes | "Myra was really fun"
AKXERAI EXPERIENCE FEEDBACK: negative | category: voice | "the voice was a little slow"
DISCOVERY: none

After save

session_summaries envelope with summary body + brand_praise shortcut + axerai_praise shortcut; conversation footer session-praise with brand quote.

Dashboard

  • Brand praise: +1
  • Brand issues: 0
  • Akxerai praise: +1
  • Akxerai issues: +1 (negative voice feedback)

If local_fallback ran instead: all counts 0 until dashboard backfill succeeds with real Archivist output.

14. Diagnosis A–F (for fix planning — not implemented)

IDItem
ACurrent Gemini prompt: MYRA_SESSION_SUMMARY_SYSTEM + summarizeSessionDialogue user prompt; explicit six dashboard block types; meaning-based classification.
BCurrent output format: Plain-text headers; praise/criticism/discovery use yes | "quote" or none; experience feedback uses positive|negative | category | "quote".
CSupabase: ledger_threads.conversation + session_summaries; praise shortcuts only for brand + Akxerai praise at envelope level.
DParser expectations: parseLabeledQuoteBlock + parseAkxeraiExperienceFeedback on session.summary body; merge shortcuts from envelope.
EProblems: local_fallback/fastExit/repair wipe signals; prompt discourages multi-block; Overview Akxerai praise tile incomplete vs tab sentiment; parser format fragility.
FRecommended fixes (future): (1) Allow multi-slice quotes across blocks in Archivist rules. (2) Preserve dashboard blocks when only digest is repaired. (3) Ensure backfill always runs / async summary after fastExit. (4) Align Overview Akxerai praise with positive experience feedback or rename tile. (5) Optional envelope shortcuts for criticism. (6) Loosen parser for multiline labels.
