4. Praise & issues — core logic (sabse zaroori)

Golden rule: Dashboard raw conversation par keyword search nahi karta praise ke liye. Signals Archivist (Gemini) ke labeled blocks se aate hain jo scan end par session_summaries column mein save hote hain. Dashboard sirf un blocks ko parse karta hai.

4.1 Scan end → Archivist (background)

Jab user session band hota hai, myraSummarize.js Archivist ko poori session dialogue deta hai. Output mein fixed DASHBOARD SIGNALS sections hote hain (meaning-based, not word lists):

  • DISCOVERY: yes | "user words" / none
  • BRAND PRODUCT PRAISE: yes | "..." / none — HOJ product, staff, showroom, packaging
  • BRAND PRODUCT CRITICISM: yes | "..." / none — shop/product complaint
  • AKXERAI PRAISE: yes | "..." / none — Myra persona, digital magic delight
  • AKXERAI EXPERIENCE FEEDBACK: positive|negative | category | "..." — tech/voice/AR/speed/confusion
  • MYRA BRAND LINES: bullets for brand prompt tab

Classification rules Archivist prompt mein defined: ek user quote ideally ek hi primary block; Myra boring = Akxerai negative (persona), staff accha = brand praise, etc.

4.2 Storage format

Har scan ek entry: --- session N summary (sender|receiver) --- with metadata (date:, duration:, optional brand_praise: / axerai_praise: shortcut lines) + full Archivist text body.

4.3 Dashboard parse pipeline

session_summaries
  → parseSessionSummaryDetails()          // myraLedger.js — per scan row
  → for each session in buildBrandDashboardAnalytics():
       summaryText = session.summary
       parseBrandProductPraise(summaryText)
       parseBrandProductCriticism(summaryText)
       parseDiscoveryFromSummary(summaryText)
       parseAkxeraiPraiseFromSummary(summaryText)
       parseAkxeraiExperienceFeedback(summaryText)
       merge with session.brandPraiseQuote / akxeraiPraiseQuote shortcuts
       push into brandPraise[], brandCriticism[], brandDiscovery[],
                     akxeraiPraise[], akxeraiFeedback[]

4.5 Backfill (dashboard Refresh)

Agar scan hua par session_summaries empty / corrupt / local_fallback: dashboard load par backfillThreadSummariesFromConversation saved conversation se Archivist dubara chala kar summary likh deta hai — tab praise/issues appear ho sakte hain. Isliye pehli baar dashboard khulne par thodi der lag sakti hai.

5. Supporting metrics (short)

  • Scanned, no talk: scan_count > 0 but session userSaid empty / “—” (sessionHadUserSpeech).
  • Per-code tokens: axerai_ai_usage / axerai_voice_usage JSON-ish log lines parsed; compared to axerai_ai_budget / axerai_voice_budget per row.
  • Age categories: first-scan picker stored on session footer; aggregated in buildAgeCategoryAnalytics.

6. Kya dashboard NAHI karta

  • Real-time websocket — Refresh button se dubara fetch.
  • Praise ke liye live regex on conversation (by design).
  • Cross-brand multi-tenant (abhi single slug HOJ pilot).
  • Legal / PII redaction beyond quote length + dump filter.

7. Operator checklist

  1. Supabase: ledger_threads_fresh_start.sql (HOJ-KOTTY @ 0) + env VITE_SUPABASE_LEDGER_TABLE=ledger_threads.
  2. Netlify build must bake same env; wrong table = column errors.
  3. After scans: Overview → Brand/Akxerai praise & issues tiles; tap for full quote list.
  4. Empty praise: check session_summaries in Supabase for Archivist blocks; hit Refresh for backfill.
